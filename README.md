# OOPLab5 — Satellite Management System (Unit Testing)

## Опис

Програма реалізує модульне тестування класу `Satellite` з попередньої практичної роботи за допомогою фреймворку MSTest.

Клас `Satellite` описує супутник із характеристиками: назва, тип, висота орбіти, дата запуску, потужність передавача, стан активності, рівень пального та категорія орбіти. Клас також містить методи для передачі даних, перемикання живлення, зміни висоти орбіти, симуляції природного зниження орбіти та розрахунку витрат пального.

Для перевірки правильності роботи класу створено тест-клас `SatelliteTests`, який охоплює логіку нестатичних і статичних методів, перевірки властивостей та обробку некоректних даних.

## Функціонал

- Тестування конструкторів класу `Satellite`
- Перевірка властивостей `Name`, `Type`, `OrbitAltitude` та `LaunchDate`
- Перевірка допустимих і недопустимих значень властивостей
- Тестування передачі даних і перемикання живлення супутника
- Перевірка зміни висоти орбіти в різних режимах роботи
- Тестування витрат пального та обробки ситуацій із недостатнім запасом пального
- Перевірка симуляції природного зниження висоти орбіти та згоряння супутника
- Тестування статичного методу `CalculateFuel`
- Перевірка методів `ToString()`, `Parse()` та `TryParse()`
- Перевірка відновлення даних супутника після перетворення в рядок і зворотного розбору
- Перевірка винятків у разі передавання некоректних параметрів

## Модульне тестування

Для тестування використовується MSTest. Тестові методи побудовані за шаблоном AAA (Arrange, Act, Assert).

У тестах застосовуються:

- `[TestClass]` — позначення класу з тестами
- `[TestMethod]` — позначення окремого тесту
- `[TestInitialize]` — підготовка тестового об'єкта перед кожним тестом
- `[TestCleanup]` — очищення тестового об'єкта після кожного тесту
- `[DataRow(...)]` — перевірка методу з різними наборами вхідних даних
- `Assert.AreEqual()` — перевірка відповідності очікуваних і фактичних значень
- `Assert.IsTrue()` та `Assert.IsFalse()` — перевірка логічних результатів
- `Assert.ThrowsExactly()` — перевірка виникнення очікуваного винятку
- `StringAssert.Contains()` та `StringAssert.StartsWith()` — перевірка вмісту рядків

## Структура проєкту

- `Program.cs` — точка входу основного проєкту
- `Satellite.cs` — клас супутника, його властивості, конструктори та методи
- `SType.cs` — перелік типів супутників
- `SatelliteTests.cs` — тест-клас із набором модульних тестів

Основний проєкт: `OOPLab5`

Тестовий проєкт: `OOPLabTests`

## Запуск тестів

Для запуску тестів через термінал перейдіть до каталогу Solution та виконайте команду:

```bash
dotnet test
```
